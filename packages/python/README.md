# publictransport

A Python client for public transport APIs. One shared model for stops, departures and trips covers several server types, so an application can query any supported network the same way. It supports servers that speak EFA (used by many German transport associations), MOTIS (the routing engine behind [Transitous](https://transitous.org)), TRIAS 1.2 and OJP 1.0.

The package wraps the Rust library of the same name. The Rust code builds the requests and parses the answers, and [httpx](https://www.python-httpx.org) sends them.

```python
from publictransport import Client, DeparturesQuery, LocationQuery, Network, Protocol

vvo = Network(
    id="vvo",
    name="Verkehrsverbund Oberelbe",
    endpoint="https://efa.vvo-online.de/std3",
    protocol=Protocol.EFA,
    timezone="Europe/Berlin",
)

with Client(user_agent="my-app/1.0 (+https://example.org)") as client:
    stops = client.locations(vvo, LocationQuery(text="Hauptbahnhof", limit=5))
    for departure in client.departures(vvo, DeparturesQuery(stop_id=stops[0].id)):
        print(departure.scheduled_time, departure.line.name, departure.direction)
```

`AsyncClient` has the same methods as coroutines.

Times are timezone-aware `datetime` objects in UTC, and `Location.timezone` names the zone to show them in. A time in a query has to be timezone-aware too, in any zone. An EFA network needs its `timezone` to send a query time. A TRIAS or OJP network needs a `requestor_ref`, which public servers document, e.g. `OpenService`.

Failures that the server or the query cause are raised as subclasses of `publictransport.Error`, such as `Error.NotFound` or `Error.RateLimited`. Failures of the HTTP exchange are raised as httpx raises them. An answer above 16 MB raises `ResponseTooLarge`.

A client can be built on an httpx client of your own, `Client(http_client=...)`, for example to use a proxy. That client has to set the `User-Agent` itself and must not follow redirects.

An application with its own HTTP stack can skip the clients: `Network.locations_request(query)` returns the request to send, and `Network.parse_locations(response)` reads the answer. Departures and trips have the same pair.

## Known limitations

The model classes are generated by [UniFFI](https://mozilla.github.io/uniffi-rs/), and type checkers stumble over the generated code in two places. Both work at runtime; a typed application needs an ignore comment there.

- `Place.ID("...")`, `Place.COORDINATE(...)` and the `TripTime` variants are rejected where a `Place` or `TripTime` is expected. Each takes its one value as a positional argument.
- pyright rejects `except Error:`. Catching a subclass such as `Error.NotFound` is accepted, and the fields of the subclasses are untyped.

`str()` of an error shows only its fields and is empty for errors without any, such as `Error.RateLimited`. Use `repr()` in messages.

## Development

The package is built with [maturin](https://www.maturin.rs) from the crate in `bindings/uniffi`. Inside the repository's nix shell:

```sh
uv sync                                          # build the Rust library, install into .venv
uv sync --reinstall-package publictransport      # again after a change to the Rust code
ruff check . && ruff format --check . && pyright
uv run pytest
```
